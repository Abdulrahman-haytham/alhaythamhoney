# الهيثم لنحل وعسل — نسخة Next.js

إعادة بناء الموقع على Next.js 16 (App Router) مع قاعدة بيانات PostgreSQL عبر Prisma، بدل نسخة Vite/React السابقة على الفرع `main`.

## المتطلبات

- Node.js **20.9 أو أحدث** (Next.js 16 لا يعمل على Node 18)
- PostgreSQL يعمل محلياً

## التشغيل محلياً

```bash
cp .env.example .env        # ثم عدّل DATABASE_URL وكلمة مرور الأدمن
npm install                 # يولّد عميل Prisma تلقائياً
npx prisma db push          # ينشئ الجداول
npm run db:seed             # الأدمن + المنتجات الثمانية + الخلطات الثلاث
npm run dev                 # http://localhost:3005
```

لوحة التحكم: `/admin/login` — بيانات الدخول من `ADMIN_USERNAME` / `ADMIN_PASSWORD` في `.env`.

## ما يوجد في هذا الفرع

| المسار | الوظيفة |
|---|---|
| `/` | الرئيسية (الأقسام مرتبة حسب قمع الشراء) |
| `/shop`, `/product/[slug]` | المتجر وصفحات المنتجات مع التقييمات |
| `/custom-mixtures/[slug]` | بنّاء الخلطات: اختيار العسل والحجم وتعديل المكوّنات بسعر فوري |
| `/articles/[slug]` | المدونة (9 مقالات) مع Schema.org |
| `/studio` | معرض صور وفيديو يرفعه الأدمن |
| `/cart` | السلة وإرسال الطلب عبر واتساب (الدفع عند الاستلام) |
| `/admin/*` | التقييمات، الخلطات (الأسعار والحدود)، الاستديو |
| `/sitemap.xml`, `/robots.txt` | تُولَّد تلقائياً من قاعدة البيانات |

## ملاحظات للنشر

- ارفع صور المنتجات في `public/images/products/` بصيغة WebP (موجودة).
- ملفات الاستديو تُكتب إلى `public/uploads/` — على استضافة serverless (مثل Vercel) نظام الملفات غير قابل للكتابة، فتحتاج تخزيناً خارجياً لهذه الميزة تحديداً.
- سجل المايغريشن غير مكتمل (بعض الجداول أُنشئت بـ `db push`)؛ قبل الإنتاج شغّل `npx prisma migrate dev` على قاعدة فارغة لتوليد سجل نظيف.
